# Invoice Data Entry Project

This sample project demonstrates my data entry skills by simulating the manual entry of 100 client invoices into an Excel spreadsheet.

## 📄 Task Description

- Created an invoice log for a business
- Captured fields such as Invoice ID, Client Name, Date, Amount, Email, and Payment Status
- Ensured proper formatting and consistent structure

## 📂 Files

- `invoices.xlsx` – Final entered data
- `generate_invoices.py` – Script used to create the data

## 💡 Skills Demonstrated

- Excel/Spreadsheet handling
- Data formatting
- Attention to detail
